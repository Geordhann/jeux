Installer sur iPhone

  1. Ouvre cette page dans Safari.
  2. Touche une appli ci-dessus pour l'ouvrir.
  3. Touche le bouton Partager (le carré avec une flèche), puis Sur l'écran d'accueil.
  4. L'appli apparaît avec son icône et s'ouvre en plein écran, comme une vraie appli.

Gratuit, sans App Store : c'est la même appli que sur Android, et les iPhone jouent dans les mêmes parties. Pas de son ? Touche l'écran une fois, puis monte le volume ; sur un iPhone ancien, désactive aussi le bouton silencieux sur le côté.

Sur Android

Télécharge l'appli (fichier APK) dans les versions publiées, ou installe la version web de la même façon depuis Chrome (menu ⋮ › Ajouter à l'écran d'accueil).

Pour jouer à plusieurs : une personne crée la partie et donne le code à 4 lettres, les autres le tapent dans « Rejoindre une partie ».

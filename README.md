# La Tournée

Jeux de soirée sur un seul téléphone qui fait le tour de la table. Ouvre `index.html` dans un navigateur, rien à installer.

- **Action ou Vérité** : 3 niveaux (Soft, Piquant, Hot), chacun son tour, joker à 2 gorgées.
- **Undercover** : mots secrets distribués en passant le téléphone, undercovers + Mr White optionnel, vote et élimination.
- **Je n'ai jamais**, **Qui pourrait…**, **Tu préfères** : paquets de cartes en 3 niveaux.

Pour ajouter des questions, modifie les listes `AOV`, `NHIE`, `QUI`, `TP` et `UC_WORDS` en haut du script dans `index.html`. Dans Action ou Vérité, `{x}` est remplacé par un autre joueur tiré au hasard.
